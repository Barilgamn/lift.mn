# LIFT.MN

Монголын лифт, эскалаторын нэгдсэн цахим портал. DELTA LIFT брэндийн танилцуулга,
засвар үйлчилгээний захиалга, сэлбэг хэрэгслийн цахим худалдааг нэг дор нэгтгэсэн.

## Урьдчилсан шаардлага

**Node.js 20 буюу түүнээс дээш хувилбар.** Өөр юу ч суулгах шаардлагагүй.

Суусан эсэхээ шалгах:

```bash
node -v
```

Хэрэв `command not found` гарвал [nodejs.org](https://nodejs.org) дээрээс **LTS** хувилбарыг
суулгаад terminal-аа хааж дахин нээнэ үү.

## Ажиллуулах

Мөр бүрийг тусад нь, өмнөх нь дуустал хүлээж байгаад ажиллуулна:

```bash
git clone https://github.com/Barilgamn/lift.mn
cd lift.mn
npm install
npm run seed
npm run dev
```

`npm run dev` нь хоёр зүйлийг зэрэг асаана: вэб (порт 3000) болон API сервер
(порт 3001). Амжилттай бол ийм бичиг гарна:

```
[web]   ➜  Local:   http://localhost:3000/
[api] API ажиллаж байна: http://localhost:3001
```

**Энэ бичиг гарсны дараа** хөтчөөрөө <http://localhost:3000> руу орно.

Удирдлагын хэсэгт орохын тулд эхлээд админ бүртгэл үүсгэнэ:

```bash
npm run create-admin
```

Имэйл, нэр, нууц үгийг асууна (нууц үг бичихэд дэлгэцэнд харагдахгүй). Дараа нь
<http://localhost:3000/admin> хаягаар нэвтэрнэ.

> Terminal цонхыг хаахгүй, `Ctrl+C` дарахгүй байх хэрэгтэй. Хаасан даруйд server
> унтарч, хөтөч дээр `ERR_CONNECTION_REFUSED` гарна.

## Тушаалууд

| Тушаал | Тайлбар |
| --- | --- |
| `npm run dev` | Вэб + API хоёуланг асаана (3000, 3001) |
| `npm run build` | Production хувилбар угсарч `dist/` дотор гаргана |
| `npm run serve` | Production горим — нэг сервер сайт ба API-г хоёуланг өгнө |
| `npm run seed` | Өгөгдлийн санд эхлэлийн өгөгдөл ачаална |
| `npm run create-admin` | Админ хэрэглэгч үүсгэнэ |
| `npm run lint` | TypeScript-ийн шалгалт (вэб ба сервер) |

## Түгээмэл алдаа

**`npm: command not found`** — Node.js суугаагүй байна. Дээрх урьдчилсан шаардлагыг үзнэ үү.

**`bun: command not found`** — `bun` шаардлагагүй. `npm` ашиглана уу.

**`Port 3000 is in use`** — Тэр портыг өөр программ эзэлсэн байна. Өөр порт дээр асаана:

```bash
npm run dev -- --port=3001
```

**`ERR_CONNECTION_REFUSED`** — `npm run dev` ажиллаагүй эсвэл зогссон байна.
Terminal дээрээ `VITE ready` бичиг байгаа эсэхийг шалгана уу.

## Хуудаснууд

Сайт нь дараах хаягтай:

| Хаяг | Хуудас |
| --- | --- |
| `/` | Портал нүүр |
| `/delta-lift` | DELTA LIFT — компанийн танилцуулга |
| `/parts` | Сэлбэг хэрэгсэл |
| `/service` | Засвар үйлчилгээ |
| `/admin` | Удирдлагын хэсэг |

Танихгүй хаяг портал руу буцаана.

### Удирдлагын хэсэг

`/admin` хаягаар нэвтэрнэ. Дотроо таван хэсэгтэй:

| Хэсэг | Агуулга |
| --- | --- |
| Хяналтын самбар | Шинэ хүсэлт, анхаарал шаардсан лифт, нөөцийн байдал |
| Бүртгэлүүд | Сайтаар ирсэн бүх маягтын хүсэлт, төлөв өөрчлөх |
| Газрын зураг | Үйлчилгээнд буй лифтүүдийн байршил, төлөвөөр өнгөөр ялгасан |
| Лифтүүд | Тоноглол бүрийн үзүүлэлт, төлөв, засварын түүх, шинэ бүртгэл нэмэх |
| Бүтээгдэхүүн | Сэлбэгийн нэр, зураг, үнэ, нөөцийн үлдэгдэл засах |

Нэвтрэлт шаардана. Админ бүртгэл үүсгээгүй бол нэвтрэх дэлгэц тэр тухай хэлж,
`npm run create-admin` тушаалыг санал болгоно.

Газрын зураг нь OpenStreetMap-ын дэвсгэр татдаг тул интернэт холболт шаардана.
Лифтүүдийн байршлын координат, засварын түүх нь эхлэлийн жишээ өгөгдөл — бодит
бүртгэлээр солино.

## Сервер ба өгөгдлийн сан

| | |
| --- | --- |
| Сервер | Express (`server/`), TypeScript, tsx-ээр ажиллана |
| Өгөгдлийн сан | SQLite — нэг файл (`data/lift.db`) |
| Нэвтрэлт | bcrypt hash + сервер дээрх session, httpOnly cookie |

### Нэвтрэлт хэрхэн ажилладаг

- Нууц үгийг **bcrypt**-ээр (cost 12) hash хийж хадгална. Эх нууц үг хаана ч
  хадгалагдахгүй.
- Session нь сервер дээр хадгалагдана. Хөтөч зөвхөн санамсаргүй ID-г
  **httpOnly** cookie-д барих тул JavaScript-ээр уншиж чадахгүй (XSS-ээс
  хамгаална). Cookie нь **SameSite=Lax**, production дээр **Secure**.
- Буруу нууц үг болон бүртгэлгүй имэйл хоёрт **ижил хариу** өгнө — ингэснээр
  аль имэйл бүртгэлтэйг таах боломжгүй.
- Нэг IP-аас 15 минутад 8 удаа буруу оролдвол түр хаана.
- Session 7 хоногийн дараа автоматаар хүчингүй болно.

### API замууд

| Зам | Эрх | Тайлбар |
| --- | --- | --- |
| `POST /api/auth/login` | нээлттэй | Нэвтрэх |
| `POST /api/auth/logout` | нээлттэй | Гарах |
| `GET /api/auth/me` | нээлттэй | Одоогийн хэрэглэгч |
| `POST /api/public/submissions` | нээлттэй | Сайтын маягт хүлээн авах |
| `GET /api/admin/bootstrap` | нэвтэрсэн | Админы бүх өгөгдөл |
| `PATCH /api/admin/submissions/:id` | нэвтэрсэн | Хүсэлтийн төлөв солих |
| `PATCH /api/admin/elevators/:id` | нэвтэрсэн | Лифтний мэдээлэл засах |
| `POST /api/admin/service-records` | нэвтэрсэн | Засварын бүртгэл нэмэх |
| `PUT /api/admin/products/:id` | нэвтэрсэн | Бүтээгдэхүүн хадгалах |
| `DELETE /api/admin/products/:id` | нэвтэрсэн | Бүтээгдэхүүн устгах |

### Нөөцлөлт

Бүх өгөгдөл `data/lift.db` файлд байна. Нөөцлөхийн тулд тэр файлыг хуулахад
хангалттай (сервер зогссон үед эсвэл `sqlite3 data/lift.db ".backup nooc.db"`).

### Байршуулах

```bash
npm install
npm run build
npm run seed          # эхний удаад л
npm run create-admin  # эхний удаад л
npm run serve         # PORT-оор порт зааж болно
```

`npm run serve` нь нэг серверээр сайт болон API-г хоёуланг өгнө — тусад нь вэб
сервер тохируулах шаардлагагүй, SPA-ийн замчлал ч ажиллана.

> **HTTPS шаардлагатай.** Production дээр cookie нь `Secure` тэмдэглэгээтэй
> явна. Энэ нь HTTPS-ээр л дамжина — энгийн HTTP дээр хөтөч cookie-г хүлээж
> авахгүй тул нэвтрэх боломжгүй болно. Домэйн дээрээ SSL гэрчилгээ (жишээ нь
> Let's Encrypt) тохируулна.

> **Хостинг дээр анхаарах:** энэ бол нэг хуудаст програм (SPA). Хэрэглэгч
> `lift.mn/delta-lift` руу шууд орох үед сервер `index.html`-ийг буцаах ёстой.
> Netlify, Cloudflare Pages дээр `public/_redirects` файл үүнийг хийнэ. Nginx
> дээр бол `try_files $uri /index.html;` мөр нэмнэ. Эс бөгөөс шууд хаягаар
> орох үед 404 гарна.

## Одоогийн төлөв

Удирдлагын хэсэг нь сервер, өгөгдлийн сан, нэвтрэлттэй бүрэн ажиллана.
Дараах зүйлс хараахан хийгдээгүй:

- **Сайтын маягтууд** (засварын хүсэлт, үнийн санал, захиалга) хараахан
  `POST /api/public/submissions` руу илгээгдээгүй — одоогоор зөвхөн дэлгэц
  дээр амжилтын мэдэгдэл харуулна. API бэлэн байгаа тул холбоход л үлдсэн.
- **Сагсны агуулга** хөтчийн `localStorage`-д хадгалагдана.
- **Эрхийн ялгаа** байхгүй — нэвтэрсэн бүх хэрэглэгч бүх зүйлийг харна,
  засна. Инженер, менежер гэх мэт үүрэг хуваах шаардлагатай бол нэмнэ.
- **Нууц үг сэргээх** урсгал байхгүй. Одоогоор шинэ нууц үгийг сервер дээр
  `npm run create-admin` эсвэл гараар тохируулна.
- Брэнд, төслийн зарим зураг Unsplash-аас гадны линкээр ачаалагдана.
